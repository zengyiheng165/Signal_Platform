# 工程模板（PS 端 DMA 通路）

> 本目录只放 **DMA 通路**的配置与用法。`dma.h` / `dma.c` / `main.c` 是固定模板（不改动）；
> 其中 `main.c` 保留了 `#include "intr.h"`、`XScuGic Intc`、`intr_init(...)` 三处**提醒**，
> 说明"实际工程要接中断"，但 `intr.c` / `intr.h` **不在本模板内**（中断控制器怎么注册、使能属于另一类问题）。

## 文件分工

| 文件 | 内容 | 改动方式 |
|---|---|---|
| `dma.h` | 中断号/超时常数、状态标志的外部声明、函数原型 | 只改常数与原型 |
| `dma.c` | `dma_init()`（`LookupConfig` + `CfgInitialize` + SG 检查）、4 个中断服务函数 | 只改基地址 |
| `main.c` | 主循环用法：分配缓冲 → Flush → 提交 → 等待 → 释放 | 照抄改参数 |
| `README.md` | 本文件 | — |

## 填空清单（每个工程必须改）

| # | 位置 | 填什么 | 从哪取 |
|---|---|---|---|
| 1 | `dma.c` 的 `XPAR_*_BASEADDR` | DMA 实例基地址 | `xparameters.h` / Block Design |
| 2 | `dma.h` 的中断号宏 | 通道对应的 GIC ID | BD / `xparameters.h` |
| 3 | `main.c` 的 `N` / `MAX_PKT_LEN` | 点数与长度表达式 | 点数 × 每点字节数 |
| 4 | `main.c` 的 `POLL_TIMEOUT_COUNTER` | 轮询上限 | 采集时间 ÷ 单次轮询开销 × 3 |
| 5 | 使用者自己的 `intr.h` / `intr.c` | 中断号与回调注册、使能 | 本模板不提供 |

> **数值来源在 PL**：DMA 模式、方向、流位宽、每次数据量都要先看 `.hwh`（或 `.xsa`）；
> 拿不到 `.hwh` 且用户未告知 ⇒ **先问用户**，不要默认参数、不要按经验假设点数。

## 三条必须保持的不变式

1. **长度 = 点数 × 每点字节数**：必须由点数推导，不允许出现与点数无关的常数。
2. **提交前 Flush**：长度按**字节**，不按点数。
3. **超时 = 整帧丢弃**：绝不复用上一帧数据参与运算或显示。

## 与"常见错误写法"的差异

| 点 | 常见写法 | 本模板 | 为什么 |
|---|---|---|---|
| 传输长度 | 写死常数 | 由点数推导 | 切档后长度不匹配 ⇒ S2MM 永不完成，且**没有错误码** |
| 等待方式 | 死等 / 加延时 | 带超时 + 整帧丢弃 | 延时只是把"永不完成"变成"偶尔完成" |
| 取数范围 | 按缓冲上限拷贝 | 只取本帧点数 | 混入上一帧旧数据 ⇒ 读到错帧、读数异常 |
| 返回值 | 不看 | 检查 `XST_SUCCESS` | 返回成功只代表"已提交"，不代表会完成 |

## 三个可复现的失败模式

1. **长度写死常数**：切到更小点数后仍按旧长度等数据 ⇒ 永不完成 ⇒ 每帧丢弃。
2. **超时后继续用旧数据**：某帧未完成仍继续测量/显示 ⇒ 读到错帧、读数异常。
3. **按缓冲上限整段拷贝**：只采到 N 点却按 2N 点拷贝 ⇒ 混入上一帧旧数据。

## 上板前自查（不动代码，只看一遍）

- [ ] 每个缓冲指针在 `Flush` / `SimpleTransfer` 之前都指向**有效地址**（没有未初始化的指针被赋进去）
- [ ] `free()` 在置 `NULL` **之前**执行（否则实际 `free(NULL)`，造成泄漏）
- [ ] `intr_init()` 处使用的 `intr.h` 由使用者提供，且已注册 4 个回调
- [ ] 传输长度表达式与 `N` 一致，且 `N > 0`

## 上板验收

- 连续 1000 帧：超时 0 次、错误 0 次
- 单帧端到端耗时 ≈ 点数 ÷ 采样率（与 `scripts/dma_len_check.py` 的估算对齐）
- 源 IP 输出递增计数 ⇒ 每帧读到的值都在变化
- 人为把长度改成错误值一次 ⇒ 能复现"永不完成"，再改回（证明检测手段有效）

## 本模板不含什么

- **中断控制器（GIC）的注册与使能**：`main.c` 只保留调用位置作提醒
- 具体算法、显示与通信协议
- 多通道带宽规划与 SG 描述符管理
