# checklist — AXI DMA 采集链路检查

> 逐项勾选；任何一项无法确认就写 `未知`，不要用"应该/大概"补位。

## 0. PL 事实（**前置门禁，必须先确认；拿不到就先问用户**）

- [ ] 已拿到 `.hwh` / `.xsa`，或用户已口述 PL 情况 ________（来源：hwh / 用户）
- [ ] AXI DMA 是否 SG 模式 ________
- [ ] 方向：S2MM / MM2S ________
- [ ] 流位宽（TDATA 字节数）________ ⇒ 每点字节数 ________
- [ ] 源 IP 每次产生的数据量（包长 / 点数）________
- [ ] 是否有 tready（接收端反压） / 是否需要触发 ________
- [ ] 采样时钟 ________
- [ ] 以上有缺项 ⇒ 已向用户列出问题清单，缺项记为 `未知`（**不允许默认或猜**）

## A. 事实确认（从源码抄，不凭印象）

- [ ] DMA 基地址 ________（`XAxiDma_LookupConfig` 实参）
- [ ] 通道方向 ________（`XAXIDMA_DEVICE_TO_DMA` / `XAXIDMA_DMA_TO_DEVICE`）
- [ ] 传输长度表达式 ________（`XAxiDma_SimpleTransfer` 第 3 实参，**抄表达式不抄注释**）
- [ ] 点数来源 ________
- [ ] 每点字节数 ________（按数据格式确定）
- [ ] 缓冲：地址 ________ / 大小 ________ / 是否 4 字节对齐 ________（Flush 时按缓存行向上取整）
- [ ] 状态标志 ________（`RxDone*` / `TxDone*` / `Error*`：谁置位、谁清零）

## B. 长度一致性（命中率最高，先查这一步）

- [ ] 长度由点数**推导**，代码里没有与点数无关的常数
- [ ] `python scripts/dma_len_check.py ...` 输出 `PASS`
- [ ] 所有"点数会变"的路径（切档、开功能）各自核对过

## C. 缓存同步

- [ ] 提交前 `Xil_DCacheFlushRange`（长度按**字节**）
- [ ] 长度没有被误传成点数/行数，且向上对齐到缓存行

## D. 提交与等待

- [ ] 顺序：清标志 → 提交 → **触发源 IP** → 等待 → 失败丢弃
- [ ] 触发源 IP 在提交**之后**
- [ ] 等待有超时；超时 = **整帧丢弃**
- [ ] 检查 `XAxiDma_SimpleTransfer` 的返回值

## E. 取数范围

- [ ] 拷贝/使用循环的边界是本帧**有效点数**，不是缓冲上限

## F. 上板验收

- [ ] 连续 1000 帧：超时 0 次、错误 0 次
- [ ] 单帧耗时 ≈ 点数 ÷ 采样率
- [ ] 源 IP 递增计数：逐帧读数在变化
- [ ] 人为改错长度一次能复现"永不完成"，再改回

## G. 红牌（出现即停）

- [ ] 只用一个"看起来对"的常数长度，不按点数推导
- [ ] 超时后继续用上一帧数据
- [ ] 提交前没 Flush，或 Flush 长度按点数而不是字节
- [ ] 把中断服务函数里的打印留在正式采集路径
- [ ] 一次改多处（长度、缓存、顺序同时动）
